## Kenapa Kitchen Set Jadi di Toko Sering Gagal di Tapak Sempit

Untuk mengatasinya, pemilik rumah biasanya menambahkan strip silikon di sela celah, padahal itu hanya menutup masalah di permukaan, bukan menghentikan kelembapan yang masuk dari belakang.

## Prinsip Desain Kitchen Set untuk Dapur Tapak Sempit

Kitchen set untuk dapur sempit itu bukan soal memilih warna. Soal penghitungan. Ada beberapa prinsip yang kami pegang di setiap proyek kitchen set rumah subsidi Batam.

**Layout mengikuti sisi dinding terpanjang.** Untuk lebar dapur di bawah dua meter, layout satu baris (one wall) atau bentuk L kecil adalah pilihan paling aman. Layout U hampir selalu gagal karena butuh lebar minimum sekitar dua setengah meter supaya orang di tengahnya masih bisa gerak.

**Lemari atas menyatu dengan plafon.** Tidak ada celah di atas, tidak ada tempat debu menumpuk. Ini membuat dapur terlihat lebih tinggi juga, sesuatu yang penting di ruangan yang lebarannya hanya dua meter.

**Lemari atas tanpa handle.** Sistem push-to-open membuat pintu lemari rata dengan badan kabinet. Handle yang menonjol di dapur sempit sering ketangkep baju atau siku saat lalu lintas ramai.

**Kolom tower untuk peralatan.** Kalau ada kulkas mini atau dispenser, jangan taruh di pinggir jalan masuk. Masukkan ke kolom tower di ujung layout supaya jalur keluarga tetap lega.

**Top table presisi dengan one set sink.** Top table granit atau taule dipotong mengikuti ukuran dapur yang diukur langsung di lokasi, bukan ukuran bawaan pabrik. One set sink dipasang dengan P-trap tertata rapi supaya pipa tidak menggantung kasar di bawah lemari bawah.

## Material Tahan Lembap dan Rayap untuk Dapur Batam

Batu Aji dan sekitarnya termasuk iklim maritim, kelembapan tinggi sepanjang tahun, plus risiko rayap dari tanah. Material kitchen set yang biasa dijual di toko umumnya papan partikel atau MDF standar, dua-duanya sangat rapuh di kondisi seperti ini. Papan partikel menggelembung kalau terkena air, MDF paling disukai rayap untuk bersarang.

Di Interior Batam, material standar kami untuk dapur adalah multipleks maritim, atau disebut juga marine plywood. Papan ini dibuat dengan lem tahan air, jadi tidak menggelembung kalau terkena kelembapan dari shared wall atau rembesan talang. Untuk budget yang lebih menyesuaikan, ada opsi PVC board yang sepenuhnya tidak mengandung kayu, artinya tidak menarik rayap sama sekali.
